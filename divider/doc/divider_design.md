# Divider IP 核设计文档

## 概述

有符号整数除法器，恢复余数法，可配位宽。输出商和余数，余数符号与被除数一致。

## 文件

```
divider/
├── rtl/divider_top.v      # 除法器顶层
├── tb/tb_divider.sv       # 测试平台
├── model/muldiv_model.c   # C golden model
└── doc/divider_design.md  # 本文档
```

## 算法

恢复余数除法（Restoring Division）：
1. 取被除数和除数的绝对值
2. 对每一位（从高位到低位）：
   - 余数左移 1 位
   - 余数 = 余数 - 除数
   - 非负 → 商位=1；负 → 商位=0，恢复余数（加回除数）
3. WIDTH 周期完成
4. 调整商和余数的符号

## 符号规则

- 商的符号 = 被除数符号 XOR 除数符号
- 余数的符号 = 被除数符号（与 C 语言 % 运算符一致）

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| WIDTH | 16 | 数据位宽 |

## 资源

- 1 个加法器/减法器
- 寄存器：~3×WIDTH
- DSP48：0
- BRAM：0

## 延迟

WIDTH + 2 周期（取绝对值1 + 移位WIDTH + 输出1）。

## 注意

- 除数为 0 时输出未定义，需外部检测
- 目前不支持除零中断，可扩展

## 验证

- 100/10 = 10 r0
- -100/10 = -10 r0
- 100/-10 = -10 r0
- 7/3 = 2 r1
- -7/3 = -2 r-1
